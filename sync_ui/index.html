修改本地代码，预览变化，再送到训练机器。

01

确认连接

填写 SSH 地址和 4090 上已存在的项目目录。第一次使用时，可在终端执行 ssh asuka@192.168.1.121，确认免密连接正常。

02

预览文件变化

预览会比较两边的文件内容。受 Git 跟踪的代码，以及未被忽略的新文件都会参与比较，包含尚未提交的修改。若本地分支有新提交，预览日志会显示待导入提交数。

03

执行同步

点击「开始同步」写入文件。被覆盖的远端版本自动保存在 .sync_4090/backups/时间/，完成后校验文件内容。

同步范围

本地分支的新提交会快进到 4090 的同名分支；未提交改动以工作区文件方式同步。docs、日志、模型、环境和缓存会保留。本地删除的文件不会自动删除远端对应文件。

若两端分支不同、远端有未提交修改，或远端包含本地没有的提交，同步会停止以保护远端状态。同步不会推送 GitHub。正在运行的训练需要重新启动或续训，才会加载新代码。
